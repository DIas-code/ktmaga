## Что входит

Математика в объёме программы общего среднего образования: уравнения, неравенства, геометрия, текстовые задачи. Это самая объёмная тема раздела «Критическое мышление» — **8 заданий из 30**, причём почти половина из них сложного уровня.

Ничего сверх школьной программы не требуется. Требуется скорость: на задание отводится в среднем **1,7 минуты**.

## Уравнения и неравенства

### Линейные

```
3x − 7 = 14   →   3x = 21   →   x = 7
```

**Неравенства** решаются так же, но с одним правилом: **при умножении или делении на отрицательное число знак переворачивается**.

```
2x − 5 < 9    →   2x < 14   →   x < 7
−2x < 8       →   x > −4          ← знак изменился
```

### Квадратные

ax² + bx + c = 0, дискриминант D = b² − 4ac:

- D > 0 — два корня: x = (−b ± √D) / 2a
- D = 0 — один корень: x = −b / 2a
- D < 0 — действительных корней нет

**Теорема Виета** для приведённого уравнения x² + px + q = 0: x₁ + x₂ = −p, x₁ · x₂ = q. Часто позволяет угадать корни за несколько секунд, не считая дискриминант.

> x² − 7x + 12 = 0 → сумма 7, произведение 12 → корни 3 и 4.

### Системы

Два основных приёма: **подстановка** и **сложение/вычитание уравнений**.

```
x + y = 12          Сложим:  2x = 16  →  x = 8
x − y = 4           Отсюда:  y = 4
```

## Проценты

Три базовые задачи:

| Тип | Формула | Пример |
|---|---|---|
| Найти процент от числа | a · p / 100 | 15% от 240 = 36 |
| Найти число по проценту | a · 100 / p | 36 — это 15% от 240 |
| Найти, сколько процентов | a / b · 100 | 36 от 240 = 15% |

**Изменение на процент** удобнее считать множителем:

- увеличить на 20% → умножить на **1,2**
- уменьшить на 20% → умножить на **0,8**

**Последовательные изменения перемножаются, а не складываются.**

```
−20%, затем +25%:   0,8 · 1,25 = 1,00   →  число НЕ изменилось
+50%, затем −50%:   1,5 · 0,5  = 0,75   →  стало меньше на 25%
```

> Это самая частая ловушка темы. Проценты берутся от **разных** баз, поэтому складывать их нельзя.

**База важна.** «На сколько процентов 510 больше 380» и «на сколько процентов 380 меньше 510» — разные вопросы:
(510−380)/380 ≈ 34%, но (510−380)/510 ≈ 25%.

## Пропорции и движение

**Прямая пропорциональность:** во сколько раз больше одно — во столько же больше другое.
**Обратная:** во сколько раз больше одно — во столько же меньше другое (скорость и время при фиксированном пути).

### Задачи на движение

| Формула | |
|---|---|
| s = v · t | путь = скорость × время |
| По течению | v + u |
| Против течения | v − u |
| Навстречу друг другу | скорость сближения = v₁ + v₂ |
| Вдогонку | скорость сближения = v₁ − v₂ |

**Разбор.** Катер прошёл 36 км по течению и вернулся, всего 5 часов. Скорость течения 3 км/ч. Найти собственную скорость.

```
36/(v+3) + 36/(v−3) = 5
36(v−3) + 36(v+3) = 5(v² − 9)
72v = 5v² − 45
5v² − 72v − 45 = 0
D = 5184 + 900 = 6084,  √D = 78
v = (72 + 78)/10 = 15 км/ч
```

### Задачи на работу

Работа принимается за **1**, производительность — доля работы в единицу времени.

**Разбор.** Вместе делают заказ за 6 часов, первый в одиночку — за 10. За сколько справится второй?

```
Вместе за час:  1/6
Первый за час:  1/10
Второй за час:  1/6 − 1/10 = 5/30 − 3/30 = 2/30 = 1/15
Значит второму нужно 15 часов.
```

### Задачи на смеси

Считайте **количество чистого вещества**, а не проценты.

```
4 л 30% + 6 л 50%:
вещества  4·0,3 + 6·0,5 = 1,2 + 3 = 4,2 л
смеси     10 л
концентрация  4,2/10 = 42%
```

> Среднее арифметическое (40%) верно только при равных объёмах. Здесь объёмы разные, и ответ смещён к более крупной части.

## Геометрия

| Фигура | Периметр | Площадь |
|---|---|---|
| Прямоугольник | 2(a + b) | a · b |
| Квадрат | 4a | a² |
| Треугольник | a + b + c | ½ · основание · высота |
| Круг | 2πr | πr² |
| Параллелограмм | 2(a + b) | основание · высота |
| Трапеция | сумма сторон | ½(a + b) · h |

**Ключевые факты:**

- Сумма углов треугольника — **180°**, четырёхугольника — **360°**.
- **Теорема Пифагора:** a² + b² = c² для прямоугольного треугольника.
- Пифагоровы тройки, которые стоит помнить: **3-4-5**, **5-12-13**, **8-15-17**, **7-24-25** и их кратные (6-8-10, 9-12-15).
- В подобных фигурах длины относятся как k, **площади как k²**, объёмы как k³.

> Площадь круга увеличили в 9 раз → радиус вырос в 3 раза, а не в 9.

**Разбор.** Диагональ прямоугольника 13, одна сторона 5. Площадь?
Вторая сторона √(169 − 25) = 12 (тройка 5-12-13). Площадь 5 · 12 = **60**.

## Комбинаторика и множества

**Формула включений-исключений** для двух множеств:

```
|A ∪ B| = |A| + |B| − |A ∩ B|
```

**Разбор.** В классе 30 человек: 18 играют в футбол, 15 — в шахматы, 8 — в оба. Сколько не занимается ничем?
Хотя бы одним: 18 + 15 − 8 = 25. Остальные: 30 − 25 = **5**.

## Последовательные числа

Обозначайте через середину — так уходят лишние вычисления.

- три последовательных: n−1, n, n+1 → сумма 3n
- три последовательных чётных: n−2, n, n+2 → сумма 3n

**Разбор.** Сумма трёх последовательных чётных чисел равна 78 → 3n = 78 → n = 26, наибольшее **28**.

## Тактика на экзамене

1. **Читайте вопрос до конца.** Часто спрашивают не то, что вы нашли: не x, а 2x + 1; не меньшее число, а большее.
2. **Подстановка вариантов.** Если уравнение неудобное, подставьте предложенные ответы — их всего пять.
3. **Прикидка.** Отбрасывайте заведомо невозможные варианты (отрицательное время, доля больше 100%).
4. **Не застревайте.** Все задания стоят одинаково — 1 балл. Пропустите тяжёлое и вернитесь.
5. **Проверяйте единицы.** Скорость в км/ч, а время в минутах — источник ошибок.

## Быстрая проверка себя

1. Решите: 5x + 3 = 2x + 18. *(x = 5)*
2. Число уменьшили на 25%, затем увеличили на 20%. Как изменилось? *(0,75 · 1,2 = 0,9 — уменьшилось на 10%)*
3. Углы треугольника относятся как 1 : 2 : 3. Найдите наибольший. *(90°)*
4. Двое красят забор за 4 часа, первый один — за 6. За сколько справится второй? *(1/4 − 1/6 = 1/12 → 12 часов)*
5. Периметр квадрата 36. Найдите площадь. *(сторона 9, площадь 81)*
