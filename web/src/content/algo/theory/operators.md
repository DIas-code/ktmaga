## Что спрашивают на тесте

Значительная часть заданий этой темы — короткие вопросы на узнавание записи.

| Формулировка | Ответ |
|---|---|
| Объект входного потока данных C++ | `cin` |
| Правильная запись стандартного потока вывода | `cout` |
| Оператор присваивания | `=` |
| Составная операция сложения | `+=` |
| Составная операция умножения | `*=` |
| Операция инкремента | `++` |
| Операция декремента | `--` |
| Оператор для выполнения условия | `if` |
| Программа начинается с выполнения функции | `main` |
| Поразрядные операции | `&`, `|`, `^`, `<<`, `>>`, `~` |
| Операция, устанавливающая биты 1 в 0, а 0 в 1 | **поразрядное НЕ** |

> Два самых частых подвоха:
> **`=` против `==`** — присваивание против сравнения;
> **поразрядное НЕ (`~`) против логического НЕ (`!`)** — инвертирует каждый бит числа
> только поразрядное. Логическое НЕ работает с истинностным значением целиком:
> любое ненулевое число превращает в 0, а ноль — в 1.
>
> В списке поразрядных операций дистракторы содержат `&&` и `||` — это ЛОГИЧЕСКИЕ
> операции, а также `+`, `*`, `/`, `%` — арифметические. С отдельными битами не работают
> ни те, ни другие.

## Классификация операторов

| Группа | Операторы |
|---|---|
| **Оператор-выражение** | Присваивание, вызов функции, инкремент |
| **Составной (блок)** | `{ ... }` |
| **Условные** | `if`, `if…else`, `switch` |
| **Циклы** | `for`, `while`, `do…while` |
| **Передачи управления** | `break`, `continue`, `return`, `goto` |
| **Пустой** | `;` |
| **Объявление** | `int a;` |

## Оператор присваивания

```c
a = 5;              // простое присваивание
a += 3;             // a = a + 3
a -= 3;  a *= 2;  a /= 2;  a %= 3;
a <<= 1; a >>= 1; a &= 0xFF; a |= 1; a ^= mask;
```

Присваивание — **выражение** со значением, поэтому допустима цепочка `a = b = c = 0` (вычисляется справа налево).

**Классическая ошибка:**

```c
if (a = 5) { ... }    // присваивание! условие истинно всегда (5 ≠ 0)
if (a == 5) { ... }   // сравнение — то, что нужно
```

## Условные операторы

### if / else

```c
if (x > 0)
    printf("положительное");
else if (x < 0)
    printf("отрицательное");
else
    printf("ноль");
```

Без фигурных скобок к `if` относится **только один** следующий оператор:

```c
if (x > 0)
    printf("A");
    printf("B");      // выполнится ВСЕГДА — не входит в if
```

`else` всегда связывается с ближайшим незакрытым `if` — «проблема висячего else». Решение: всегда ставить `{}`.

### switch

```c
switch (expr) {          // expr — целое или символ (не строка, не double!)
    case 1:
        printf("один");
        break;
    case 2:
    case 3:              // объединение веток
        printf("два или три");
        break;
    default:
        printf("другое");
}
```

**Проваливание (fall-through)** без `break` — главный источник тестовых заданий:

```c
int x = 2;
switch (x) {
    case 1: printf("A");
    case 2: printf("B");     // ← вход здесь
    case 3: printf("C"); break;
    default: printf("D");
}
// Вывод: BC
```

Управление входит в `case 2`, печатает `B`, затем **проваливается** в `case 3`, печатает `C`, и только там `break` прерывает `switch`.

Метки `case` требуют **константных** выражений; диапазоны (`case 1..5`) стандартом не поддерживаются.

## Циклы

```c
for (инициализация; условие; шаг) тело
```

Любая из трёх частей может быть пустой: `for (;;)` — бесконечный цикл.

```c
// Несколько переменных через запятую
for (int i = 0, j = n - 1; i < j; i++, j--) { ... }

// while — проверка ДО тела
while (n > 0) { n /= 2; }

// do…while — тело минимум один раз
do { scanf("%d", &x); } while (x < 0);
```

**Главное различие `while` и `do…while` — момент проверки.** У `while` условие проверяется до входа, поэтому тело может не выполниться ни разу; у `do…while` тело идёт первым, и хотя бы один раз оно отработает всегда. Это классический вопрос на тесте.

```
    while (x < 0) { ... }          do { ... } while (x < 0);

        ┌─ проверка ─┐                 ┌──▶ тело
        │            │                 │      │
        ▼            │                 │      ▼
     условие ──нет──▶ выход            └── условие ──нет──▶ выход
        │ да         │                        │ да
        ▼            │                        │
      тело ──────────┘                        └── назад в тело

    при x = 5:                     при x = 5:
    тело не выполнится ни разу     тело выполнится 1 раз
```

**Порядок работы `for`:**

```
    for (i = 0; i < 3; i++)  тело

    1. инициализация  i = 0        (один раз)
    2. проверка       0 < 3  ✓
    3. тело
    4. шаг            i = 1
    5. проверка       1 < 3  ✓  →  тело  →  i = 2
    6. проверка       2 < 3  ✓  →  тело  →  i = 3
    7. проверка       3 < 3  ✗  →  выход

    тело выполнилось 3 раза, но i на выходе равно 3
```

**Типичные ошибки:**

```c
for (int i = 0; i <= n; i++)   // ошибка «на единицу»: n+1 итерация
    sum += a[i];               // a[n] — выход за границу массива

while (i < n);                 // лишняя точка с запятой → пустое тело, зависание
{ ... }
```

## Операторы передачи управления

| Оператор | Действие |
|---|---|
| `break` | Немедленно выходит из **цикла** или `switch` |
| `continue` | Пропускает остаток итерации, переходит к следующей |
| `return` | Выходит из функции, возвращая значение |
| `goto метка` | Безусловный переход |

```c
for (int i = 0; i < n; i++) {
    if (a[i] < 0) continue;    // отрицательные пропускаем
    if (a[i] == target) break; // нашли — выходим
    sum += a[i];
}
```

`break` выходит только из **одного** (ближайшего) цикла.

## Ввод-вывод

### Язык C — stdio.h

```c
int    n;
double x;
char   name[50];

scanf("%d", &n);            // & обязателен для скаляров
scanf("%lf", &x);           // %lf для double при вводе
scanf("%49s", name);        // для массива & не нужен; ограничиваем длину

printf("%d\n", n);          // целое
printf("%5d\n", n);         // ширина поля 5
printf("%.2f\n", x);        // 2 знака после запятой
printf("%s\n", name);       // строка
printf("%c\n", 'A');        // символ
printf("%x %o\n", 255, 8);  // hex, oct
printf("%p\n", (void*)&n);  // адрес
```

| Спецификатор | Тип |
|---|---|
| `%d`, `%i` | `int` |
| `%u` | `unsigned int` |
| `%ld`, `%lld` | `long`, `long long` |
| `%f` | `float` в `printf`, **`double` тоже** |
| `%lf` | `double` в `scanf` |
| `%c` | `char` |
| `%s` | Строка (`char*`) |
| `%%` | Сам символ `%` |

Посимвольный ввод-вывод: `getchar()`, `putchar()`. Строки: `fgets(buf, size, stdin)` — безопасная замена устаревшей `gets`, которая удалена из стандарта.

`scanf` возвращает число успешно прочитанных элементов — это стоит проверять:

```c
if (scanf("%d", &n) != 1) { /* ошибка ввода */ }
```

## Структура программы

```c
#include <stdio.h>       // 1. Директивы препроцессора
#include <stdlib.h>

#define MAX 100          // 2. Макросы

int counter = 0;         // 3. Глобальные объявления

int square(int x);       // 4. Прототипы функций

int main(void) {         // 5. Главная функция
    printf("%d\n", square(5));
    return 0;
}

int square(int x) {      // 6. Определения функций
    return x * x;
}
```

**Прототип** нужен, если функция вызывается раньше своего определения. `main` — точка входа: именно её вызывает среда выполнения. `return 0` из `main` означает успешное завершение.

## Переход от схемы алгоритма к программе

| Блок схемы (ГОСТ 19.701) | Конструкция языка |
|---|---|
| Овал «начало/конец» | `int main() { ... return 0; }` |
| Параллелограмм (ввод-вывод) | `scanf` / `printf` |
| Прямоугольник (процесс) | Присваивание, вычисление |
| Ромб (решение) | `if`, `switch` |
| Шестиугольник (подготовка) | `for` |
| Прямоугольник с двойной рамкой | Вызов функции |

**Пример.** Схема: «начало → ввод n → S = 0, i = 1 → пока i ≤ n: S += i, i++ → вывод S → конец».

```c
int main(void) {
    int n, s = 0;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
        s += i;
    printf("%d\n", s);
    return 0;
}
```
