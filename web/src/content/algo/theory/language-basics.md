## Алфавит и структура программы

Алфавит языка C/C++ составляют латинские буквы, цифры, знак подчёркивания и специальные символы. **Идентификатор** начинается с буквы или `_`, далее — буквы, цифры, `_`; регистр различается (`sum` и `Sum` — разные имена).

```c
#include <stdio.h>          // подключение заголовочного файла

int global = 0;             // глобальная переменная

int main(void) {            // точка входа
    int a = 5;              // объявление с инициализацией
    printf("%d\n", a);
    return 0;               // код возврата ОС
}
```

## Типы данных

| Тип | Размер (типично) | Диапазон / назначение |
|---|---|---|
| `char` | **1 байт всегда** | Символ или маленькое целое |
| `short` | 2 байта | −32 768 … 32 767 |
| `int` | 4 байта | ≈ ±2,1 млрд |
| `long long` | 8 байт | ≈ ±9,2·10¹⁸ |
| `float` | 4 байта | ≈ 7 значащих цифр |
| `double` | 8 байт | ≈ 15 значащих цифр |
| `_Bool` / `bool` | 1 байт | 0 или 1 |
| `void` | — | «Нет типа» |

> По стандарту гарантирован только **`sizeof(char) == 1`** — байт как раз и определяется как размер `char`. Размеры остальных типов зависят от платформы; гарантированы лишь соотношения `char ≤ short ≤ int ≤ long ≤ long long`.

**Почему у типа есть предел.** Число хранится в фиксированном количестве битов, и как только значение перестаёт в них помещаться, старшие биты просто отбрасываются — происходит **переполнение**. Для типа со знаком старший бит отведён под знак, поэтому диапазон делится примерно пополам между отрицательными и положительными.

```
    char — 1 байт = 8 бит

    signed char:   ⌊знак⌋ 7 бит значения   →  −128 … 127
                     │
                     ▼
                   [ s │ 0 0 0 0 0 0 0 ]

    unsigned char:  все 8 бит значения     →     0 … 255

                   [ 0 0 0 0 0 0 0 0 ]

    переполнение:  127 + 1  →  −128     (для signed char)
                   255 + 1  →     0     (для unsigned char)
                            «счётчик прокрутился по кругу»
```

Отсюда классическая ловушка: `unsigned int a = -5;` не даёт ошибки, а превращается в очень большое положительное число, потому что битовая комбинация −5 читается как беззнаковая.

**Модификаторы:** `signed` / `unsigned` (со знаком / без), `short` / `long` (размер), `const` (нельзя менять), `static`, `extern`.

## Константы и переменные

```c
const double PI = 3.14159;      // типизированная константа (предпочтительно)
#define MAX 100                 // макрос препроцессора, без типа
enum Color { RED, GREEN, BLUE };  // RED = 0, GREEN = 1, BLUE = 2
```

Литералы: `42` (int), `42L` (long), `42U` (unsigned), `3.14` (double), `3.14f` (float), `'A'` (char), `"текст"` (строка), `0x1F` (шестнадцатеричное), `075` (восьмеричное — ведущий ноль!), `0b1011` (двоичное, C23/C++14).

**Область видимости:** переменная, объявленная внутри блока `{}`, видна только там. Глобальные переменные видны везде и по умолчанию инициализируются нулём, локальные — **мусором**, если не инициализированы явно.

## Выражения

### Арифметические операции

```c
int a = 7, b = 2;
a + b   // 9
a - b   // 5
a * b   // 14
a / b   // 3   ← ЦЕЛОЧИСЛЕННОЕ деление, дробная часть отбрасывается
a % b   // 1   ← остаток; только для целых
```

**Главная ловушка:** если оба операанда целые, деление целочисленное.

```c
int a = 7, b = 2;
printf("%d", a / b);            // 3
printf("%f", (double)a / b);    // 3.500000  ← приведение хотя бы одного операнда
printf("%f", 7.0 / 2);          // 3.500000
```

Остаток `%` для отрицательных чисел в C99 усекается к нулю: `-7 % 2` равно `-1`.

### Инкремент и декремент

```c
int i = 5;
int a = i++;    // a = 5, i = 6   (постфикс: сначала вернуть, потом увеличить)
int b = ++i;    // i = 7, b = 7   (префикс: сначала увеличить, потом вернуть)
```

### Операции сравнения и логические

| Операция | Значение |
|---|---|
| `==`, `!=` | Равно, не равно |
| `<`, `>`, `<=`, `>=` | Сравнение |
| `&&` | Логическое И |
| `\|\|` | Логическое ИЛИ |
| `!` | Логическое НЕ |

В C нет отдельного логического типа в классическом понимании: **0 — ложь, любое ненулевое значение — истина**. Результат сравнения — 0 или 1.

**Короткое замыкание:** в `a && b` второй операнд не вычисляется, если первый ложен; в `a || b` — если первый истинен. Это позволяет писать безопасные проверки:

```c
if (p != NULL && p->value > 0) { ... }   // разыменование только при p != NULL
if (i < n && arr[i] == x) { ... }        // защита от выхода за границу
```

### Побитовые операции

| Операция | Действие | Пример |
|---|---|---|
| `&` | Побитовое И | `12 & 10` = 8 (`1100 & 1010 = 1000`) |
| `\|` | Побитовое ИЛИ | `12 \| 10` = 14 (`1110`) |
| `^` | Исключающее ИЛИ | `12 ^ 10` = 6 (`0110`) |
| `~` | Инверсия | `~5` = −6 |
| `<<` | Сдвиг влево | `5 << 2` = 20 (умножение на 2²) |
| `>>` | Сдвиг вправо | `20 >> 2` = 5 (деление на 2²) |

Полезные идиомы: `x & 1` — проверка на нечётность; `x << k` — умножение на 2ᵏ; `x ^ y ^ y == x`.

## Структуры алгоритмов

### Линейная

Операторы выполняются последовательно, сверху вниз.

### Разветвляющаяся

```c
if (condition) {
    /* ветвь «истина» */
} else if (other) {
    /* ещё условие */
} else {
    /* иначе */
}

int max = (a > b) ? a : b;     // условная операция
```

### Циклическая

```c
// Счётный цикл: известно число повторений
for (int i = 0; i < n; i++) { ... }

// Цикл с предусловием: проверка до тела, может не выполниться ни разу
while (condition) { ... }

// Цикл с постусловием: тело выполняется минимум один раз
do { ... } while (condition);
```

**Сколько итераций у `for (int i = 0; i < 5; i++)`?** i принимает значения 0, 1, 2, 3, 4 — ровно **5**.

**Управление циклом:** `break` выходит из цикла целиком, `continue` пропускает остаток текущей итерации.

### Вложенные циклы

```c
int count = 0;
for (int i = 1; i <= 3; i++)
    for (int j = 1; j <= i; j++)
        count++;
// count = 1 + 2 + 3 = 6
```

Общее число итераций внутреннего цикла — сумма его границ. При `j <= i` для i от 1 до n получается n(n+1)/2 — треугольный обход.

Полный вложенный цикл `for i < n; for j < n` даёт **n²** итераций.

## Метки и goto

```c
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        if (a[i][j] == target) goto found;
found:
    printf("Найдено\n");
```

Метка — идентификатор с двоеточием. `goto` считается плохим стилем; единственное относительно приемлемое применение — выход сразу из нескольких вложенных циклов.
