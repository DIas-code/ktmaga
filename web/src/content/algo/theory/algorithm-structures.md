## Линейные алгоритмы

Последовательность действий без ветвлений и повторов.

```c
// Площадь и периметр прямоугольника
double a, b;
scanf("%lf %lf", &a, &b);
double area = a * b;
double perimeter = 2 * (a + b);
printf("S = %.2f, P = %.2f\n", area, perimeter);
```

**Сложность.** Линейный алгоритм состоит из фиксированного числа действий, не зависящего от данных, поэтому его сложность — **O(1)**. Сколько бы операций ни было записано подряд, это константа.

**Обмен значений двух переменных** — обязательно через временную:

```c
int t = a;
a = b;
b = t;
```

Наглядно, почему без временной не выходит:

```
    правильно (через t)              неправильно (a = b; b = a)

    a=5  b=9  t=?                    a=5  b=9
    t = a  →  a=5  b=9  t=5          a = b  →  a=9  b=9   ← 5 потеряна
    a = b  →  a=9  b=9  t=5          b = a  →  a=9  b=9
    b = t  →  a=9  b=5  t=5
              ✓ обменялись                     ✗ обе равны 9
```

Первое присваивание затирает исходное значение `a`, и восстановить его уже неоткуда — поэтому его и сохраняют заранее.

## Разветвляющиеся алгоритмы

```c
// Корни квадратного уравнения
double d = b * b - 4 * a * c;
if (d > 0) {
    printf("%.4f %.4f\n", (-b + sqrt(d)) / (2*a), (-b - sqrt(d)) / (2*a));
} else if (d == 0) {
    printf("%.4f\n", -b / (2*a));
} else {
    printf("Действительных корней нет\n");
}
```

> Сравнение вещественных чисел через `==` ненадёжно из-за погрешности. Правильно: `if (fabs(d) < 1e-9)`.

```c
// Максимум из трёх
int max = a;
if (b > max) max = b;
if (c > max) max = c;
```

## Циклические алгоритмы

### Накопление суммы и произведения

Приём один и тот же: заводится переменная-накопитель, и на каждом шаге в неё «доливается» очередной элемент. Начальное значение обязано быть **нейтральным элементом** операции — тем, которое её не меняет: для сложения это 0, для умножения 1. Если начать произведение с нуля, оно нулём и останется навсегда.

```c
int sum = 0;             // нейтральный элемент сложения
for (int i = 1; i <= n; i++) sum += i;

long long fact = 1;      // нейтральный элемент умножения
for (int i = 1; i <= n; i++) fact *= i;
```

```
    n = 5

    i:      1     2     3     4     5
    sum:  0→1   1→3   3→6  6→10 10→15      сумма  = 15
    fact: 1→1   1→2   2→6  6→24 24→120     факт.  = 120
```

**Сложность.** Один проход по n элементам — **O(n)** времени и **O(1)** памяти: накопитель один, независимо от размера данных.

### Поиск максимума

Идея та же — накопитель, только вместо суммы в нём хранится «лучшее на данный момент» значение. Начинать нужно с **существующего элемента** массива, а не с нуля: если все числа отрицательные, ноль так и останется ответом, хотя его в данных нет.

```c
int m = a[0];                    // начинаем с существующего элемента,
for (int i = 1; i < n; i++)      // а не с нуля — иначе на отрицательных данных ошибка
    if (a[i] > m) m = a[i];
```

```
    a = [ -7  -2  -9  -1  -5 ]

    старт   m = a[0] = -7
    i=1     -2 > -7  →  m = -2
    i=2     -9 > -2? нет
    i=3     -1 > -2  →  m = -1
    i=4     -5 > -1? нет
                        ответ: -1   ✓

    при старте с m = 0 ответом стал бы 0 — числа, которого в массиве нет
```

**Сложность.** **O(n)** — каждый элемент сравнивается ровно один раз; меньше нельзя, ведь пропущенный элемент мог оказаться максимумом.

Если нужен ещё и индекс:

```c
int best = 0;
for (int i = 1; i < n; i++)
    if (a[i] > a[best]) best = i;
```

### Работа с цифрами числа

```c
int n = 12345, sum = 0, count = 0, rev = 0;
int t = n;
while (t > 0) {
    int d = t % 10;      // последняя цифра
    sum += d;
    rev = rev * 10 + d;  // переворот числа
    count++;
    t /= 10;             // отбросить последнюю цифру
}
// sum = 15, count = 5, rev = 54321
```

## Одномерные массивы

```c
int a[5] = {1, 2, 3, 4, 5};
int b[5] = {0};                   // все элементы — нули
int c[] = {1, 2, 3};              // размер выведен: 3
```

**Индексация с нуля:** у массива из n элементов допустимы индексы 0…n−1. Обращение к `a[n]` — выход за границу; C этого не проверяет, программа просто читает чужую память.

```c
// Ввод и вывод массива
for (int i = 0; i < n; i++) scanf("%d", &a[i]);
for (int i = 0; i < n; i++) printf("%d ", a[i]);
```

### Типовые операции

```c
// Сумма и среднее
int s = 0;
for (int i = 0; i < n; i++) s += a[i];
double avg = (double)s / n;        // приведение обязательно!

// Подсчёт по условию
int cnt = 0;
for (int i = 0; i < n; i++) if (a[i] % 2 == 0) cnt++;

// Реверс на месте
for (int i = 0, j = n - 1; i < j; i++, j--) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}                                   // ровно n/2 обменов

// Сдвиг влево на одну позицию
for (int i = 0; i < n - 1; i++) a[i] = a[i + 1];

// Удаление элемента с индексом k
for (int i = k; i < n - 1; i++) a[i] = a[i + 1];
n--;

// Вставка значения v на позицию k
for (int i = n; i > k; i--) a[i] = a[i - 1];
a[k] = v;
n++;
```

> Реверс делает **n/2** итераций, а не n: указатели идут навстречу и встречаются в середине. Если сделать n итераций, массив развернётся дважды.

## Двумерные массивы

```c
int m[3][4];                       // 3 строки, 4 столбца
int t[2][3] = {{1,2,3}, {4,5,6}};

for (int i = 0; i < 3; i++)
    for (int j = 0; j < 4; j++)
        scanf("%d", &m[i][j]);
```

В памяти двумерный массив расположен **по строкам** (row-major): сначала вся строка 0, затем строка 1.

```c
// Главная диагональ: i == j
int diag = 0;
for (int i = 0; i < n; i++) diag += m[i][i];

// Побочная диагональ: i + j == n - 1
for (int i = 0; i < n; i++) anti += m[i][n - 1 - i];

// Выше главной диагонали: j > i
// Ниже главной диагонали: j < i

// Сумма по каждой строке
for (int i = 0; i < n; i++) {
    int s = 0;
    for (int j = 0; j < m; j++) s += a[i][j];
    printf("Строка %d: %d\n", i, s);
}

// Транспонирование квадратной матрицы на месте
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++) {     // j начинается с i+1!
        int t = a[i][j]; a[i][j] = a[j][i]; a[j][i] = t;
    }
```

## Строковые данные

В C строка — массив `char`, завершающийся нулевым символом `'\0'`.

```c
char s[20] = "Привет";     // занимает 7 байт: 6 символов + '\0'
char t[] = "abc";          // размер 4
```

### Функции string.h

| Функция | Действие |
|---|---|
| `strlen(s)` | Длина **без** `'\0'` |
| `strcpy(dst, src)` | Копирование |
| `strcat(dst, src)` | Конкатенация |
| `strcmp(a, b)` | 0 при равенстве, <0 если a < b, >0 если a > b |
| `strchr(s, c)` | Указатель на первое вхождение символа |
| `strstr(s, sub)` | Указатель на первое вхождение подстроки |

```c
strlen("Hello")      // 5, хотя в памяти строка занимает 6 байт
strcmp("abc","abd")  // отрицательное число
```

> Сравнивать строки через `==` нельзя — так сравниваются адреса, а не содержимое. Только `strcmp`.

### Обработка символов (ctype.h)

```c
isalpha(c)  isdigit(c)  isspace(c)  isupper(c)  islower(c)
toupper(c)  tolower(c)
```

```c
// Подсчёт гласных
int v = 0;
for (int i = 0; s[i] != '\0'; i++)
    if (strchr("аеёиоуыэюяАЕЁИОУЫЭЮЯ", s[i])) v++;

// Реверс строки
int n = strlen(s);
for (int i = 0, j = n - 1; i < j; i++, j--) {
    char t = s[i]; s[i] = s[j]; s[j] = t;
}

// Проверка на палиндром
int ok = 1;
for (int i = 0, j = strlen(s) - 1; i < j; i++, j--)
    if (s[i] != s[j]) { ok = 0; break; }
```

Символы — это числа: `'A'` = 65, `'a'` = 97, `'0'` = 48. Отсюда идиомы: `c - '0'` превращает символ цифры в число, `c + 32` переводит заглавную латинскую букву в строчную.
